📋 ASSET CREATION GUIDELINES
=====================================================

🎨 VISUAL STYLE RECOMMENDATIONS:
- Cute and casual design mood (as requested)
- Bright, warm colors suitable for a cooking game
- Clean, simple art style that's easy to read
- Consistent character design across all customer sprites
- Food graphics should look appetizing and clear

🔊 AUDIO STYLE RECOMMENDATIONS:
- Cheerful, upbeat background music
- Clear, satisfying sound effects for interactions
- Varied customer voice/emotion sounds
- Cooking sounds should be realistic but pleasant
- UI sounds should be crisp and responsive

✨ EFFECT RECOMMENDATIONS:
- Particle effects should be colorful but not overwhelming
- Customer emotion effects should be clearly distinguishable
- Cooking effects should provide clear feedback
- All effects should match the cute, casual art style

💡 NOTES FOR DESIGNERS
=====================================================

- This is a hotteok (Korean pancake) cooking simulation game
- The game involves customer service, cooking timing, and sales
- Customer satisfaction is a key gameplay element
- The visual style should be cute and appealing to casual gamers
- Audio should provide clear feedback for all player actions
- All assets should work well together as a cohesive package

Total Budget Estimate: 111 unique assets
Estimated Development Time: 5-7 weeks for full asset creation

📋 CHARACTER DESIGN NOTES:
- Character Spot 1: Young/teenager customers (6 variations)
- Character Spot 2: Adult customers (6 variations) 
- Character Spot 3: Elderly/unique customers (6 variations)
- Each variation should maintain the character spot's theme while offering visual diversity
- Random selection ensures no repetitive customer appearances
